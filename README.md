## 3. Projet Final (Blog)

Application de blog complète avec authentification et gestion de base de données.

- **Authentification Sécurisée** : Inscription et connexion avec hachage des mots de passe (Bcrypt) et protection des routes via JSON Web Tokens (JWT).
- **Opérations CRUD Complètes** : Création, lecture, modification et suppression d'articles.
- **Gestion des Droits** : Seul l'auteur d'un article peut le modifier ou le supprimer grâce à une vérification côté serveur (authorId).
- **Interface Moderne (Dark Mode)** : 
    - Mise en page responsive avec **CSS Grid** et **Flexbox**.
    - Utilisation de `line-clamp` pour une gestion propre des textes longs.
    - Formulaires stylisés et centrés pour une meilleure expérience utilisateur.
- **Stack Technique** : React (Vite), Node.js, Express, Axios, React Router.
